This project is basically a service that makes sure you don't forget things when you leave the house! When you walk up to it, it detects your face and asks where you're going. If you say something like "I'm going shopping," it will tell you exactly what you need to remember to bring.

I hope you enjoy it!
  How It Works & What's Included
MagicMirror Screen: Runs a MagicMirror dashboard with custom widgets and plays music through the USB speakers.

AI Camera Face Detection: Uses the Raspberry Pi AI Camera to handle face detection so the Raspberry Pi 5 doesn't have to do all the hard work itself.

Audio Setup: Uses a USB microphone to listen for where you're going and a mini USB speaker to talk back to you.

3" Deep Shadow Box: Putting everything inside a 3" deep shadow box was the best choice so the screen, Pi 5, cooler, and cables all fit with plenty of space.
